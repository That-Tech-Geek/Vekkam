# Implementation Roadmap

### Phase 1 — Document intelligence
PDF/page extraction, OCR, image extraction, OpenCV preprocessing, region detection and canonical IR.

### Phase 2 — Graph & visual intelligence
Graph detection, axis/line detection, vision interpretation, table/equation parsing, graph IR and reconstruction.

### Phase 3 — Knowledge + blueprint
Concept extraction, prerequisite inference, Neo4j/Qdrant adapters, blueprint generation and scene templates.

### Phase 4 — Manim compiler
Template rendering, static validation, render validation, visual validation and pedagogical validation.

### Phase 5 — Narration + assembly
Kokoro/Piper, mathematical normalization, WhisperX timestamps, timing manifests, FFmpeg and captions.

### Phase 6 — Exam mastery
Question generation, graph/diagram questions, active recall, Socratic rescue, FSRS and prerequisite-aware scheduling.

Post-MVP: PYQ mining, personalization and model optimization.
