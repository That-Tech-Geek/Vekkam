# Metrics

## Extraction
text accuracy, equation accuracy, graph detection accuracy, table extraction accuracy.

## Generation
blueprint validity, Manim render success, visual defect rate, mathematical correctness.

## Learning
first-attempt recall, delayed recall, transfer performance, time-to-mastery.

## System
processing time, GPU/CPU cost, storage per chapter, failure/retry rate.

## Product
minutes studied, concepts mastered, reviews completed, PYQ improvement.

Long-term metric: exam-relevant retrieval and transfer improvement per hour spent in ExamForge.
